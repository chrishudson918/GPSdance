## Build vs. buy + tech stack (2026-11-05, user's list)

- GoldWave research corrected two early assumptions: **GoldWave Infinity** (a browser version included with every license) is listed for ChromeOS, and GoldWave has a **Censor** tool plus transcription. They aren't connected, so words are still found and selected by hand. GoldWave costs $59 lifetime or $19 a year per user, with no education pricing listed. It has no Drive integration, no sharing and no practice player. VISION.md's "why build" section was corrected (user's OK).
- Recommendation approved by the user: build, with a free GoldWave Infinity trial on a Chromebook as the January 1 fallback; decision point after the proof of concept. Written in docs/build-vs-buy.md and published as the Claude doc "Build vs. Buy: Dance Music Software" (https://claude.ai/artifact/2XYgz1csbokRFJyseGsAtk).
- Tech stack approved (docs/design/tech-stack.md): TypeScript + React + Vite (the user had no language preference, so the pick is the most common stack, for handoff), Web Audio, Signalsmith Stretch, web-audio-beat-detector, our own LUFS and WAV code, lamejs, fflate, Google Identity + Picker + Drive with drive.file.
- **One project = one .gpsmix file** (zip with the edit list + song copies). Reason: under drive.file it's unclear whether picking a folder grants access to the files inside it (Google's docs are silent and community reports conflict). One file makes Editor/Viewer sharing and Drive version history work cleanly.
- The user's picks: test on a student Chromebook (they can borrow one); personal Gmail accounts in a personal Google Cloud project for early Drive tests, district accounts once the admin approves.

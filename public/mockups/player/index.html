Player mockups

Three clickable versions of the practice Player, in the Editor's option A look. There is no real sound, but the clock, 8-count, sections, loops, count-in, speeds and set list all work. All three share the features you picked; they differ in how progress is shown, where the controls sit, and how the Big view (for across the room) is laid out. Editor mockups

Option A

  • Controls in a bar along the bottom
  • Big view stacked: section name, a giant 8-count · beat, then the time

Things to try in each one

  • Press Play (or Space): it starts right away, with no count-in.
  • Click a section button: it jumps there and counts in first (Count-in 4 = "5, 6, 7, 8"; 8 = a full 8-count; Off = no count-in).
  • Press a section's loop icon. Turn "Count-in between loop passes" on and off to compare.
  • Pick a practice speed: you'll see "Getting it ready…", then it carries on.
  • Switch to Big view and step back from the screen. Esc or "Normal view" goes back.
  • The set list is the project's songs in the Editor's order (the Player can't change it). Click a song to play from it; click near the end of the progress to see the next song start by itself.
